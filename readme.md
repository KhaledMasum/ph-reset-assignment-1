১। Null হচ্ছে যখন আমরা ইচ্ছাকৃতভাবে কোনো Variable এর Empty ভেল্যু সেট করি। আর Undefined হচ্ছে যখন কোনো Variable এর ভেল্যু সেট করা হয় না। মানে এক্সেস করার সময় পাওয়া যায় না।

২। Map ফাংশন Array এর প্রতিটা Element নিয়ে একটা নতুন Array রিটার্ন করে। Map ফাংশন নতুন Array কে ভেরিয়েবলের মধ্যে রিটার্ন করে, 'Foreach' কোনো নতুন Array রিটার্ন করে না।

৩। "==" শুধু ভেল্যু চেক করে, "===" ভেল্যু এবং টাইপ দুটোই চেক করে।

৪। আমরা জানি Javascript মূলত Synschronous ভাবে কাজ করে। মানে Javascript কোড Line by Line এক্সিকিউট হয়। কিন্তু অনেক সময় কিছু কাজ আমাদের Asynschronous ভাবে করতে হয়। যেমন কোনো API রিকোয়েস্ট করলে সেটা Asynschronous ফাংশন ব্যবহার করে করি আমরা। Async/Await যখন ব্যবহার করি তখন সেই Asynschronous কাজটি দেখতে Synschronous কাজের মতো মনে হয় কিন্তু কাজ করে Asynschronous ভাবেই।

৫। Scope হচ্ছে বাউন্ডারি বা সীমারেখা। প্রতিটা ভেরিয়েবল এর নিজস্ব Scope থাকে। যার বাইরে তাকে এক্সেস করা যায় না। Scope সাধারনত ৩ ধরনের হয়। "Global scope", "Function scope", "Block scope". গ্লোবাল Scope এ কোনো ভেরিয়েবলকে ডিফাইন করলে যে কোনো যায়গা থেকে সেটা এক্সেস করা যায়। ফাংশন স্কোপের ভেরিয়েবল শুধু ঐ ফাংশনের ভিতরে এক্সেস করা যায়। আর ব্লক স্কোপ মানে হচ্ছে যে কোনো ব্রাকেটের ভিতরে কোনো ভেরিয়েবল ডিফাইন করলে ওই ব্রাকেটের বাইরে থেকে সেটা আর এক্সেস করা যায় না।
